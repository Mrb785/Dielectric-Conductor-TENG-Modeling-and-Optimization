
## Overview

This project focuses on the theoretical modeling, simulation, validation, and optimization of a **dielectric–conductor triboelectric nanogenerator (TENG)** using **MATLAB/Simulink**.

The work investigates the electrical response of a dielectric–conductor TENG under **contact–separation excitation** and studies the influence of dielectric material properties and external load resistance on the generated electrical output.

The project also explores the potential use of the TENG as a **self-powered sensing element for footstep detection**, where the electrical response generated by mechanical excitation can serve as the sensing signal.

---

## Objectives

The main objectives of the project are:

1. Develop a theoretical and Simulink-based model of a dielectric–conductor TENG.
2. Validate the developed models against established theoretical and published results.
3. Compare the performance of different dielectric materials.
4. Investigate the effect of load resistance on the generated power.
5. Study the output of the TENG with a full-wave rectifier (FWR).
6. Explore a self-powered application based on footstep detection.

---

## Methodology

The project follows a sequential modeling, validation, comparison, and optimization workflow:

```text
Theoretical TENG Model
        ↓
MATLAB/Simulink Implementation
        ↓
Model Validation
        ↓
Dielectric Material Comparison
        ↓
Full-Wave Rectifier (FWR)
        ↓
Load Resistance Optimization
        ↓
Application Study
        ↓
Self-Powered Footstep Detection
```

The dielectric material comparison uses the same underlying dielectric–conductor model structure while changing the relevant material parameters. The model is subsequently extended with a full-wave rectifier and used for load-resistance optimization.

## Model Validation

Two validation stages were carried out to establish the theoretical basis and verify the implemented models.

### 1. Infinite Parallel-Plate Benchmark

The initial TENG model was implemented based on the theoretical framework reported by **Niu et al.**

The model was used to reproduce the analytical benchmark for a contact-mode TENG.

The following quantities were evaluated:

- Open-circuit voltage
- Transferred charge

Validation results:

- [`Niu_Validation_Charge.png`](Results/Validation/Niu_Validation_Charge.png)
- [`Niu_Validation_Voltage.png`](Results/Validation/Niu_Validation_Voltage.png)

### 2. Dielectric–Conductor Model

The dielectric–conductor model was implemented based on the theoretical framework reported by **Dharmasena et al.**

The implemented model was validated through comparison with theoretical results.

The following quantities were evaluated:

- Transferred charge
- Short-circuit current

Validation results:

- [`DDEF_Validation_Charge.png`](Results/Validation/DDEF_Validation_Charge.png)

## Material Comparison

Five dielectric materials were investigated using the dielectric–conductor TENG model:

- PDMS
- PTFE
- Nylon
- Kapton
- PVC

### Material Parameters

| Material | Triboelectric Surface Charge Density, σT (μC/m²) | Relative Permittivity, εr |
|---|---:|---:|
| PDMS | 30 | 3.24 |
| PTFE | 100 | 2.0 |
| Nylon | 120 | 3.5 |
| Kapton | 80 | 3.4 |
| PVC | 60 | 3.5 |

### Simulation Conditions

| Parameter | Value |
|---|---:|
| Length, L | 5 cm |
| Width, W | 5 cm |
| Dielectric thickness, d | 220 μm |
| Load resistance, R | 1 GΩ |
| Maximum separation, H | 2.5 mm |
| Frequency, n | 1 Hz |
| Temperature | 298 K |

### Mechanical Input

The mechanical contact–separation motion used in the simulations is represented by:

```math
z(t) = H[\sin(2\pi nt + 3\pi/2) + 1]
```

## Full-Wave Rectifier

A **full-wave rectifier (FWR)** was incorporated into the dielectric–conductor TENG model to investigate the rectified electrical output.

The rectified model was subsequently used for the **load-resistance optimization study**.

The FWR implementation enables the generated alternating electrical response from the contact–separation process to be analyzed as a rectified output across an external load.

A representative FWR Simulink model is available at:

[`Simulink/DDEF_Nylon_fwr.slx`](Simulink/DDEF_Nylon_fwr.slx)

## Load Resistance Optimization

A load-resistance sweep was performed to investigate the effect of external load resistance on the **average output power**.

For the Nylon FWR model, the optimization produced:

| Parameter | Result |
|---|---:|
| Optimal Load Resistance | 1 GΩ |
| Maximum Average Power | 2.719894 × 10⁻⁴ W |
| Maximum Average Power | ≈ 0.271989 mW |

The resulting load-resistance optimization plot is stored at:

## Application: Self-Powered Footstep Detection

The final application explored in the project is **self-powered footstep detection**.

The objective is to investigate the feasibility of using the electrical response generated by a TENG under mechanical excitation as a sensing signal, potentially enabling footstep detection without a conventional external power source.

The concept builds upon the simulated TENG response and investigates its potential as a sensing mechanism for mechanical events such as footsteps.

> **Scope note:** The footstep-detection component is presented as an application study and future development based on the simulation work. A physical footstep detector has not been fabricated or experimentally validated as part of the work described in this repository.
